🌟 Sobre o Projeto
O OrçaPro Gold foi desenvolvido para transformar a maneira como profissionais independentes e empresas apresentam seus valores aos clientes. Esqueça os orçamentos genéricos em planilhas ou PDFs sem graça.
Com uma identidade visual moderna em Preto, Dourado e Branco, a plataforma entrega percepção de alto valor imediata, além de automatizar o envio de propostas diretamente para o WhatsApp do cliente.
✨ Funcionalidades
￼ 💎 Design Premium Luxo: Paleta de cores selecionada para transmitir autoridade e sofisticação.
￼ ⚡ Edição em Tempo Real: Edite valores, itens, prazos e dados do cliente com visualização instantânea do documento final.
￼ 📱 100% Responsivo: Funciona perfeitamente no computador, tablet ou celular (iOS/Android).
￼ 💬 Envio Direto via WhatsApp: Gera mensagens formatadas e prontas para disparo em um clique.
￼ 🖨️ Exportação PDF & Impressão: Layout otimizado para gerar arquivos PDF perfeitos sem quebras de página.
￼ 💾 Salvamento Local: Seus dados e rascunhos ficam armazenados no navegador com segurança.

📲 Integração com WhatsApp
O projeto conta com um script de backend integrado para conexão via API de WhatsApp (Evolution API / Z-API), permitindo:
1. Envio do resumo do orçamento direto no chat.
2. Anexo do documento PDF gerado automaticamente.
3. Comunicação automatizada com robôs de atendimento.
🚀 Como Usar
